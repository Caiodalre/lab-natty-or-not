# Prompt utilizado

## Objetivo

Gerar uma imagem fotorrealista para o projeto **São Paulo 2045: Natty ou IA?**.

## Prompt principal

```text
Use case: photorealistic-natural
Asset type: imagem principal de um projeto educacional para README no GitHub

Primary request: fotografia documental extremamente realista de um bairro
sustentável fictício de São Paulo no ano de 2045, mostrando um futuro plausível
que possa ser confundido à primeira vista com uma fotografia contemporânea.

Scene/backdrop: avenida urbana brasileira em uma manhã levemente nublada após
chuva, calçadas molhadas, edifícios residenciais de uso misto, telhados verdes,
árvores maduras, ciclovia protegida e um ônibus elétrico discreto.

Subject: pedestres diversos indo ao trabalho e estudantes caminhando
naturalmente, sem ninguém posando para a câmera.

Style/medium: fotografia editorial fotorrealista, aparência de câmera full-frame
com lente 35 mm, cores naturais e leve granulação, detalhes cotidianos e
pequenas imperfeições reais.

Composition/framing: formato paisagem, ponto de vista ao nível dos olhos,
profundidade convincente, cena equilibrada e espontânea.

Lighting/mood: luz difusa realista de manhã nublada, reflexos sutis no asfalto
molhado, atmosfera otimista porém sóbria.

Materials/textures: pele natural, tecido usado, concreto, vidro, vegetação e
marcas realistas no pavimento.

Constraints: futuro próximo plausível; arquitetura brasileira; mãos e rostos
anatomicamente coerentes; sem marcas, logotipos, placas legíveis, texto,
marcas-d'água ou estética de ficção científica exagerada.

Avoid: neon cyberpunk, carros voadores, prédios impossíveis, aparência de render
3D, excesso de retoque, poses publicitárias e multidão caótica.
```

## Estratégia do prompt

O prompt combina três grupos de instruções:

- **Contexto:** define São Paulo, o ano de 2045 e um futuro sustentável;
- **Realismo fotográfico:** especifica lente, luz, textura e composição;
- **Restrições:** reduz exageros futuristas, elementos de marca e artefatos
  típicos de imagens artificiais.
